# Watch pages, CSP and share-link downloads

- Share-link downloads are off for good: migration `000076` sets every `download_enabled` false, defaults it false and adds the check `videos_share_downloads_off`. Code that sets it true fails in the database. Staff download (`GET /api/videos/{id}/download`) does not read the column.
- The page CSP is `script-src 'self' 'nonce-…'`, which silently blocks inline event attributes (`onclick=`, `oncontextmenu=`; the browser logs a `script-src-attr` violation). Attach listeners in nonced script instead.
- `playerJS` (`player_shared.go`) runs on the watch and embed pages and, through `playlistJS`, on both playlist pages. Put a player-wide behaviour there and assert it in `TestEmbedPage_Success_RendersVideoPlayer`, `TestPlaylistWatchPage_Success` and `TestPlaylistEmbedPage_RendersWorkspaceAccent`.
- To check a rendered page in a browser without running the stack, copy a `watch_page_test.go` mock into a temporary `zz_dump_*_test.go` that writes `rec.Body` to a file. Serve it with the CSP header and nonce `test-nonce`, then drive it with Playwright from `web/node_modules/.pnpm/playwright@1.63.0/node_modules/playwright`. The browsers cached in `~/Library/Caches/ms-playwright` are older builds, so pass `executablePath` (Chromium: `chromium-1234/chrome-mac-arm64/Google Chrome for Testing.app/Contents/MacOS/Google Chrome for Testing`; Firefox: `firefox-1538/firefox/Nightly.app/Contents/MacOS/firefox`). WebKit is not cached. Hide `#player-overlay`, `#player-error` and `#player-spinner` before clicking the video, because they cover it while paused.
- DB tests: `accountDB(t)` gives each test a freshly migrated database. Throwaway server: `docker run -d --rm --name pg-x -p 127.0.0.1:55476:5432 -e POSTGRES_PASSWORD=synthetic postgres:17-alpine`, then `TEST_DATABASE_URL=postgres://postgres:synthetic@127.0.0.1:55476/postgres?sslmode=disable`.
- 24 `internal/video` DB tests (thumbnail, edit and derived-result tests) fail locally on `main` too. Before blaming a change, compare the `--- FAIL` list against a `git worktree add --detach` of the base.
- Use `GOTOOLCHAIN=go1.26.11` (the `go.mod` version), because the local Go is newer. Validate OpenSpec with `npx -y @fission-ai/openspec validate <change> --strict`.
- The name under the video is `users.name`, joined live in `WatchPage` (`internal/video/watch_page.go`, `.video-meta`). MPD staff get it from the grant's `profile.displayName` on sign-in and each grant refresh (`applyProfile` in `internal/mpd/staff_profile.go`); without one it stays the Cognito `name` or "MPD staff" from `provision`. The photo lives in `mpd_staff_photos` and managed pages inline it as a data URL (`managedCreatorPhoto` in `mpd_pages.go`).
- `decodeGrant` (`internal/mpd/grant.go`) ignores unknown fields, so mpd-api can add grant fields without a schema bump. `validateSession` re-fetches the grant about every 30 s. The photo is fetched from `MPD_ACCESS_URL` + `/photo` only when `photoVersion` changes.
- mpd-api is the source for staff names and photos: `staff.first_name/last_name/photo_s3_key` and `display_name(..., is_doctor)` ("Dr" prefix). SendRec-client tokens only resolve on `_is_sendrec_route` paths in `staff_token_authenticator.py`. Read another repo's current main without touching its checkout: `git archive origin/main | tar -x -C <scratch>`.
- pgxmock v5: an expectation without `WithArgs` only matches a call with no arguments. A page-dump test that skips `WithArgs` silently falls through to the error branch.
